# Sprite Forge

[English README](./README.en.md)

一个小型全栈素材处理工具，包含四条独立工作流：

- `视频处理`：上传视频，自动截帧、去背景、逐帧微调并导出精灵表。
- `多视频拼帧`：从多个视频中分别截取关键帧，对齐校准后合并为一套精灵表。
- `提取要素`：上传纯色背景素材图，自动识别图块、逐块识别主体去背景并导出结果。
- `图片处理`：对单张图片一键去除背景（支持多种识别模式）或框选区域去除水印，即时下载结果。

> 仅个人兴趣使用，请勿商用。

## 技术栈

- 前端：React 18、TypeScript、Vite、React Router、SWR、Tailwind CSS
- 后端：FastAPI、Pillow、OpenCV、rembg

## 安装

先准备：

- Node.js 18+
- Python 3.10+
- ffmpeg 5.0+（含 ffprobe，用于视频截帧与元数据解析）
- 首次使用「标准」或「保守」去背景模式时，rembg 会自动联网下载 u2net 模型（约 176MB）

安装依赖：

```bash
npm run setup
```

这会安装根目录依赖、`apps/web` 前端依赖，以及 `services/api/requirements.txt` 中的 Python 依赖。

## 开发

同时启动前后端：

```bash
npm run dev
```

单独启动前端：

```bash
npm run dev:web
```

单独启动后端：

```bash
npm run dev:api
```

默认情况下：

- Web: `http://localhost:6284`
- API: `http://localhost:8000`

## 构建

前端生产构建：

```bash
npm run build
```

这个命令等价于：

```bash
npm --prefix apps/web run build
```

构建产物位于 `apps/web/dist`。

## 使用说明

进入首页后可以选择四条入口：

### 1. 视频处理

适合把短视频或动作片段转成精灵资源。

主要功能：

- 上传 `MP4` / `WebM`
- 自动按帧数或步长截帧，支持键盘快捷键（空格标记、左右箭头逐帧）
- 可选水印区域处理
- 三种去背景模式：标准（干净边缘）、保守（保留光效/光晕）、白色（仅去除纯白背景）
- 生成 spritesheet 预览
- 结果页支持拖拽调整帧顺序、逐帧 X/Y 偏移微调
- 逐帧播放预览动画效果
- 可选灯光归一化，统一亮度和对比度
- 多目标导出：逐帧 PNG ZIP、GIF 动画、精灵表 + JSON、Godot 4、Unity、Cocos Creator

典型流程：

1. 上传视频
2. 选择截帧方式（支持键盘逐帧标记）
3. 检查帧列表
4. 设置处理参数和去背景模式
5. 在结果页拖拽排序、微调偏移、归一化灯光
6. 选择导出格式下载

### 2. 多视频拼帧

适合从多个动画片段中各取关键帧，合并生成一套精灵资源。

主要功能：

- 添加多个视频源，分别设置截帧数量
- 预览各视频的关键帧
- 对齐校准：选择基准视频与目标视频，通过 X/Y 偏移和叠加预览精确对齐
- 三种去背景模式：标准、保守（保留光效）、白色（仅去除纯白背景）
- 可选灯光归一化
- 支持拖拽调整合并帧顺序
- 多目标导出：逐帧 PNG ZIP、精灵表 + JSON、GIF 动画、Godot 4、Unity、Cocos Creator

### 3. 提取要素

适合处理纯色背景、元素彼此分离的 UI 图集或素材板。

主要功能：

- 支持多图上传，每张图独立检测图块，最终合并为一个精灵表
- 基于 LAB 色彩距离自适应识别图块边界，兼容任意纯色背景与素材内部间隙
- 检测结果以蓝色边框和编号叠加显示，方便确认
- 按图块识别主体并去除外部纯色背景
- 横向网格预览，支持拖拽调整顺序和单个删除
- 点击任意图块可放大查看原图
- 逐帧播放预览动画效果
- 多目标导出：逐项 PNG ZIP、GIF 动画、精灵表 + JSON、Godot 4、Unity、Cocos Creator

典型流程：

1. 上传一张或多张素材图
2. 逐张确认自动识别到的图块（蓝色边框叠加预览）
3. 设置精灵表列数和间距
4. 处理并预览结果
5. 拖拽调整顺序，点击放大确认，选择导出格式下载

### 4. 图片处理

适合对单张图片做快速修饰，即传即得。

主要功能：

- 支持多图上传，每张图独立选择处理方式
- 去除背景：四种模式可选——标准识别（主体分割）、保守模式（保留光效/光晕）、白底优化（仅去除纯白背景）、纯色背景（任意纯色底）
- 去除水印：在图片上框选水印区域，使用 OpenCV inpaint 修复
- 处理结果与原图对比预览，透明背景以棋盘格衬托
- 一键下载 PNG 结果

典型流程：

1. 上传一张或多张图片
2. 逐张选择去除背景或去除水印（去水印需先框选区域）
3. 点击"开始处理"，等待结果
4. 对比原图并下载

## 目录说明

- `apps/web`：前端应用
- `services/api`：FastAPI 服务
- `data`：运行时上传文件、任务结果和临时文件

## 备注

- 提取要素当前假设素材是纯色背景，且图块之间有明显空白分隔。
- 去背景的"白色"模式仅去除纯白/近白区域，适合自带光效的素材；"保守"模式会保留半透明边缘和光晕。"纯色"模式可去除任意纯色背景，用于提取要素与图片处理工作流。
- `data/` 下内容是运行时生成文件，不建议手动编辑。
